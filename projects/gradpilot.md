# GradPilot

**Context:** Personal career-planning web project for IT and cybersecurity graduates.  
**Stage:** Prototype in development.  
**Approach:** AI-assisted development with iterative user review and refinement.

## Purpose

Bring a user's profile, skills, career assessment and next steps into one workspace, with exploration of GitHub-based skill analysis.

## Existing repository structure

- Authentication pages and callback route.
- Profile form and skills manager.
- Career-assessment questions, scoring engine and interface.
- Dashboard and roadmap views.
- GitHub connection UI and repository-analysis route.
- Supabase integration and database migration.

## Technology

Next.js 16.2.6, React, TypeScript, Tailwind CSS, Supabase, Zustand, React Hook Form and Zod, as recorded in the repository manifest.

## Status and evidence

Source: the existing private `lalsaif-ai/gradpilot` repository, including its manifest and source tree. Authentication and interface work have been exercised during development. This portfolio review did not run a complete build, end-to-end suite or security assessment.

AI CV generation, an AI career assistant and job-intelligence work were listed as later phases in the repository README. Their completion is not claimed here.

The source repository remains private. This page provides a public project summary.

**Skills practiced:** web development, component-based UI, data modeling, authentication integration, state management and project documentation.
