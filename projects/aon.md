# AON — Adaptive Online Protection

**Context:** Graduation Project I, Majmaah University, academic year 2026–2027.  
**Role:** Team member in a five-student graduation project.  
**Stage:** Research, requirements and proposed system design.

## Problem and approach

The project investigates whether interaction behavior can complement phishing-message indicators when choosing warnings. The proposed implementation is an installable Android prototype in a controlled environment, with a synthetic mailbox and test links that stay inside the experiment.

## Work documented in GP1

- Related-work review and comparison of behavioral and phishing-related approaches.
- Project scope, functional/nonfunctional requirements and system models.
- Design of a personal baseline and a threat-plus-behavior risk approach.
- Privacy-conscious collection plan using interaction timing and derived metrics.
- Proposed evaluation with 20 adult volunteers and two baseline sessions, subject to required approvals.

The design includes a dedicated experimental keyboard. It is intended to derive timing and correction metrics without retaining the participant's typed text. Public dataset features must be audited before model development; the public typing reference is not a phishing-labeled dataset.

## Evaluation plan

Compare threat-only and threat-plus-behavior conditions using simulated link choices, warning responses, response times and usability measures.

## Evidence and limits

Source: the team's current `AON_GP1_Final_Report.pdf`. The report, models and study plan are prepared. Android implementation, participant recruitment, data collection and outcome evaluation remain future work. This summary does not claim trained-model performance or production protection.
